Inkwell 7.42 for the Mac mini (Apple Silicon)
=============================================

WHAT IS HERE
------------
- builds/: the ready-made 7.42 Mac app for the Mac mini (unzip, drag Inkwell.app to Applications). Download it and follow
  "READ ME FIRST - MAC MINI.txt".
- The build kit: the same files GitHub Actions builds from
  (.github/workflows/build-mac.yml). A push to main builds again
  and publishes the result as a release of this repository.
- WORKFLOW build-mac.yml (copy).txt: the workflow as a plain text file.
- INKWELL_HANDOFF_v7p*.txt: the notes from each version, newest last.
- LICENCE.txt: all rights reserved; no licence is granted.

Look for "v7.42" beside the date at the top of Inkwell to know this
version is running.

The Mac mini runs the stronger writing models and, from 7.42, serves Inkwell itself to an iPhone or iPad on the home Wi-Fi (Studio, Engine, Share).
